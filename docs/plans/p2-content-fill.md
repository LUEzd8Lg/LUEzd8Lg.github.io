## 3. 技术处理项（我来做，随方案记录）

1. **立绘改名**：`resolveEntryImage`（app.js:4156）按 `data/deities/{id|code}.{png,jpg,jpeg,webp}` 探测，含中文空格的文件名（`OG-P01 白曐.png`）不会命中。重命名为 `OG-P01.png` 等（或在 JSON 写 `img` 字段，二选一，推荐改名）。
2. **立绘压缩**：12 张合计约 19 MB，需压到每张 ≤ 300 KB（System.Drawing 重编码，参照 2026-10-18 优化流程）。
3. **JSON 生成**：产出 `data/deities.json` / `data/eras.json` / `data/timelines.json` → 跑 `tools/merge-manifest.ps1` 重建 `merged.js`。
4. **缓存版本**：`index.html` 的 `data/*.js?v=` 升一档。
