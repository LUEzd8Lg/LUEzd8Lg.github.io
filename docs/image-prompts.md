# 盖亚世界观 · 图片生成提示词（交给生图方）

> 用途：本站页头横幅 / 占位图。以下提示词已按**站点的实际渲染条件**校准，不是通用模板。
>
> **关键约束（先读）**：站点 CSS 会对横幅图强制做 `grayscale(1) contrast(1.12) brightness(0.45~0.5)`，
> 并在**下三分之一**叠加由透明到近黑的渐变遮罩（`rgba(5,5,5,0.96)`）。
> 因此：
> 1. **颜色会被抹掉**——提示词不要指望彩色出效果，一律按「黑白高对比」构图。
> 2. **下三分之一会变很暗**——主体必须放在上 2/3，下方留空/留暗。
> 3. 参考图在 `IMG-03 组织名录页头图.png`、`IMG-05 神祇图鉴页头图.png`。

## 一、通用规格（所有横幅通用）

| 项 | 值 |
|---|---|
| 尺寸 | **1920×1080**（16:9）。CSS 用 `background-size: cover` 裁切，不需要严格 1920×400 |
| 格式 | PNG 或高质量 JPG |
| 色调 | 黑白 / 冷灰单色，高对比，银盐颗粒感 |
| 构图 | 主体在上 2/3；下 1/3 留暗或留空 |
| 禁止 | 文字、水印、logo、边框、拼贴、彩色高饱和 |
| 风格词 | `cinematic still, high contrast monochrome, silver-gelatin grain, volumetric light, epic scale, no text` |

**通用负面提示词**：
```
text, watermark, logo, letters, signature, border, frame, colorful, saturated colors, cartoon, anime, low contrast, blurry, cluttered, busy lower third
```

## 二·补 文件体积提醒（待优化）

两张图都偏大：横幅 2.25 MB、占位图 3.46 MB。它们会被 CSS 再压缩一次（灰度 + 压暗），原始分辨率高于实际需要。

| 文件 | 当前 | 建议 | 理由 |
|---|---|---|---|
| `正典层级页横幅.png` | 2.25 MB | **≤ 300 KB** | 显示宽度约 1600px，1672px 够用，但需压 PNG 或转 JPG |
| `无封面档案的默认占位图.png` | 3.46 MB | **≤ 200 KB** | 卡片缩略图最大显示约 320px，1254px 严重过量 |

> 占位图是多卡片复用的，3.46 MB 在慢网下会明显拖慢首屏。建议：缩到 640×640 后转 JPG(质量 82) 或 PNG-8。
> 压缩后**保持文件名不变**即可，无需改代码。
