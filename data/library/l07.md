# 盖亚 · 纪元与纪年基准

> 本文件是**全书时间线的唯一裁判**。任何文件里的年份与此处冲突，一律以本文件为准。
> 建立背景：41 份材料转换完成后，发现**四套互不兼容的纪元体系**。这里逐条拆解、定基准、给换算规则。
>
> 生成日期：2026-10-18

---

## 一、四套纪年体系对照（这是全部混乱的根源）

| # | 体系 | 出处 | 纪元划分 | 白曐年代 |
|---|---|---|---|---|
| ① | **世界史制** | `世界史·大升级版` | 一 前3000–300／二 300–**1900**／三 1900–2300／四 2300–今 | **前 3000** |
| ② | **洲史制** | 四份洲史 | 一 前3000–300／二 300–**1700**／三 1700–2300／四 2300–今 | 前 3000 |
| ③ | **圣物制** | 天教·圣源教·EDC 三份《修订版》档案 | 不分纪元 | **前 8000 本体坠落 + 前 1500 碎片二次显影** |
| ④ | **彼岸制** | `彼岸·增补设定集` | 不分纪元，按事件编号 | **前 1500** |

### 冲突点拆解

**冲突 A：第一纪元的终点**

- 世界史说第二纪元从 **公元 300** 开始（旧神黄昏结束）。**这点三方一致**。
- 但结束点：世界史续到 **1900**，洲史却断在 **1700**。
- 原因：世界史把「启明时代 1700–1900」算作**第二纪元末期**；洲史把它划入**第三纪元开端**。
- 这纯粹是**分段口味差异**，不是设定冲突。四洲史内部也不统一（南洲的第三纪元从 1704 起）。

**冲突 B：白曐的年代 —— 这是真正的硬伤**

| 说法 | 支持文件 | 问题 |
|---|---|---|
| 前 3000 | 世界史、四洲史、第一巨人、彼岸（事件 4.1 前的叙述） | —— |
| 前 8000 + 前 1500 | 天教档案、圣源教档案、EDC 档案（三份《修订版》都写了同一句「白曐设定统一」） | 若本体在前 8000 坠落，则「天坠之始＝前3000」整条线要重排 |
| 前 1500 | 彼岸设定集 4.2（「白曐降临 约公元前1500年」） | 与它自己 4.1 的伊尔萨接触（前3000）时序颠倒 |

**冲突 C：巴别塔有几座、在哪年**

| 说法 | 出处 | 年份 |
|---|---|---|
| 第一纪元巴别塔（奥尔菲斯） | 世界史 | **前 665** |
| 巴别塔启动 → 事故 → 第十三层显现 | 世界史 | **2295 / 2296 / 2296** |
| 「巴别塔事件」= 第十三层凭空显现 | 红月政府档案·逻各斯之子档案·圣源教档案 | **2247** |
| 第二代巴别塔（EDC 建造） | 彼岸设定集 | **约 1920** |
| 第一纪元巴别塔 | 彼岸设定集 | **约公元 200** |

**冲突 D：「今」是哪一年**

- 世界史年表止于 **2402 静态维持**，之后没有年份。
- 之前的整理曾定「今 = 红月 100 年 = 公元 2412」，但**这条没有出现在任何原始 docx 里**，是本库自己的推演。

## 二、基准裁决

### 2.1 纪元基准（**强制**）

采用**世界史制**为主轴，因为它是唯一同时覆盖四洲、并给出完整年表的文件。

| 纪元 | 起 | 止 | 内含阶段 |
|---|---|---|---|
| **第一纪元** 神在人间 | 前 3000 | 公元 300 | 天坠之始 / 众灵年代 / 英雄纪元 / 诸城邦时代 / 六道之战 / 埃尔德时代 / 旧神黄昏 |
| **第二纪元** 无神者的纪元 | 公元 300 | **1900** | 神隐之年 / 灰疫年代 / 伪神年代 / 黑烛时代 / 神弃战争 / **启明时代（1700–1900）** |
| **第三纪元** 触碰边界 | 1900 | 2300 | 解析时代 / 遗迹时代 / 异常工业时代 / 巴别塔时代 / 理性黄昏 |
| **第四纪元** 静态纪元 | 2300 | 今 | 灾变纪 / 红月肇始 / 秩序扩张 / 黄金时代落幕 / 静态维持 |

> **洲史制的处理**：四份洲史把第二纪元写成「300–1700」，把启明时代挪进第三纪元。
> **裁决：以世界史制为准。** 洲史若要引用，把它的「第三纪元 1700–2300」理解为**世界史第三纪元的前段**即可，内容不变，只是编号偏移。
> 写正文时统一写「第二纪元末期·启明时代」，不写「第三纪元启明时代」。

### 2.2 白曐基准（**需你拍板**）

三个候选，各有代价：

| 方案 | 内容 | 好处 | 代价 |
|---|---|---|---|
| **方案甲（推荐）** | **本体前 8000 坠落，碎片前 3000 砸入中州，前 1500 二次显影** | 一次收编三份《修订版》档案，全都不用改；且能解释「血矿」为何是远古地层矿 | 世界史要改「前 3000 白曐坠落」的措辞为「前 3000 白曐碎块砸入中州」 |
| 方案乙 | 一律前 3000 | 世界史一个字不改 | 天教·圣源教·EDC 三份档案全部要改；血矿成因要重写 |
| 方案丙 | 一律前 1500（彼岸制） | 与彼岸设定集一致 | 与所有洲史、巨人记录、英雄纪元全部脱节，改动最大 |

> **本库暂按方案甲记录**（在 `08·命名与专名表` 里标为「待定-甲」）。
> 若你不表态，写作时**只写「白曐坠落」不写具体年份**，可以完全绕过这个问题。

### 2.3 巴别塔基准（**可裁决**）

问题在于「巴别塔事件」这个词被四种含义混用。拆开就好：

| 名称 | 年份 | 是什么 | 出处 |
|---|---|---|---|
| **初代巴别塔** | 前 665 | 奥尔菲斯天宫文明所建，塔崩，史称「巴别塔事件」 | 世界史·诸城邦 |
| **二代巴别塔** | 2265–2290 建造 | 人类为「缝合薄膜」所建，十三层 | 世界史·巴别塔时代 |
| **巴别塔启动** | 2295 | 第 13 层自行激活，记录显示「来」 | 世界史 |
| **巴别塔事故** | 2296 | 探针过载，裂口出现在塔顶正上方 | 世界史 |
| **第十三层显现 / 六字信息流** | **2295**（不是 2247） | 「你们终于停止等待」 | 世界史 |
| **巴别塔时代** | 2247–2300 | 一个**时代名**，起点是「裂环之影」首次显现 | 世界史 |

**裁决：**
1. 红月政府档案、逻各斯之子档案、圣源教档案里写的「巴别塔事件 = 公元 2247 年」→ **应为「2247 年裂环之影首次显现」**，是巴别塔时代的**开端**，不是事故本身。
2. 圣源教档案称「2247 年第十三层显现，全球祭坛同时失去感应」→ 按世界史，那应该是 **2295 年**（第 13 层激活那一夜）。
3. 彼岸设定集的「第二代巴别塔约 1920 年，由 EDC 建造」→ **与世界史冲突**。世界史里 1920 年是解析时代，异常工业要到 2200 才开始。建议改为「**2280 年代，EDC 参与二代巴别塔的材料供应**」，或直接废弃这条。

### 2.4 「今」的基准

**事实**：原始文件全部止于 2402，**没有任何一份文件写过「现在」是哪一年。**

| 选项 | 年份 | 含义 |
|---|---|---|
| **今 = 红月 88 年** | 公元 2400 | 最保守，紧贴 2398「黄金时代落幕」 |
| **今 = 红月 100 年** | 公元 2412 | 静态维持已十年，秩序开始紧绷 |
| **今 = 红月 110 年** | 公元 2422 | 二十年的「紧绷的和平」，适合末世感 |

**建议：今 = 红月 100 年（公元 2412）**，理由：
- 静态维持（2402）已运行十年——足够长到能看出裂缝，不够长到已经崩了；
- 给「塞拉芬·雷恩上台（2382）」留出三十年，正好是一代人的统治期；
- 红月纪元整整一百年，是个叙事的整数节点。

> 写作时若不确定，用「当下」「如今」代替具体年份，不会出错。

## 三、换算规则

### 3.1 三套纪年的换算

```
红月纪元（新历）＝ 公元 − 2312
公元 ＝ 新历 + 2312
世界史「前××年」＝ 公元前××年
```

注意两处特例：
- 红月政府档案写「公元2320年 = 红月元年（新历8年）」→ 这是把 **2312 记为「新历 0 年」**、把 **2320 记为「元年」**。**两套并存会乱，统一用「新历＝公元−2312」**。
- 天火研究所档案的「新历 48 年 = 公元 2360 年」符合上式（2312+48=2360）✅

## 四、年表可信度分级

材料里的年份并非同等可靠。写作时按级取用：

| 级 | 含义 | 范围 | 处理 |
|---|---|---|---|
| **S** | 卡死 | 2295 / 2296 / 2300 / 2312 / 2342 / 2360 / 2402 | 可写具体年份 |
| **A** | 可靠 | 前1620 / 前653–629 / 公元0 / 300 / 900–1100 / 1662 / 1700 / 1850 / 1900 / 2200 | 可写具体年份 |
| **B** | 有分歧 | 白曐全部年代、前 1200 前 800 等上古年份、四洲各自内战 | 写「约」，或只写世纪 |
| **C** | 不可用 | 战争总表前 2600 系列、标「500年」混入 1480 附近的条目 | **不要引用**，见 N6 |
| **X** | 版本疑点 | 2247 vs 2295 的巴别塔、前8000 白曐 | 按第二节裁决 |

## 五、需要你拍板的三件事

1. **白曐**：甲/乙/丙？（推荐甲：本体前8000 + 碎片前3000 + 二次前1500）
2. **「今」**：2400 / 2412 / 2422？（推荐 2412）
3. **纪元编号**：是否接受洲史的「1700 划界」作为**内容**、但对外统一用世界史的**编号**？

定了这三条，`02·纪元时间轴` 就能从「两套并存」合并成唯一版本。
